# Three Games

Three standalone interactive fiction games, each playable as a single HTML file in your browser. Each game comes in both English and Simplified Chinese (中文).

## Games

| Game | English | 中文 |
|------|---------|------|
| The Clockmaker's Heart | [Play](clockmakers-heart.html) | [开始](clockmakers-heart-zh.html) |
| Saltline | [Play](saltline.html) | [开始](saltline-zh.html) |
| Tidewright | [Play](tidewright.html) | [开始](tidewright-zh.html) |

## How to Play

Download any `.html` file and open it directly in your browser — no installation or server required. Your progress is saved locally in the browser.
